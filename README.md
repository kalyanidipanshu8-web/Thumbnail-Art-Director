# 🎨 Thumbnail Art Director

**Turn YouTube thumbnail references into AI-assisted design directions.**

Thumbnail Art Director is a Claude Skill that analyses YouTube thumbnail references, identifies their visual design patterns and creates detailed prompts for AI image generation.

Instead of starting with a blank canvas, start with a design direction you love.

## ✨ Features

- **8 Built-in Styles:** Explore eight predefined thumbnail design styles.
- **Reference Analysis:** Give Claude one or multiple thumbnail references to analyse.
- **Custom Styles:** Add your own references to explore additional design directions.
- **Image Generation Prompts:** Generate detailed prompts to use with AI image generators.
- **Design Variations:** Bring generated thumbnails back into Claude and explore alternative directions.
- **Design Handbook:** Learn about the principles behind effective thumbnail design.

## ⚡ How It Works

1. Upload one or multiple YouTube thumbnail references.
2. Let Claude analyse their visual patterns.
3. Choose a design direction.
4. Generate an image-generation prompt.
5. Use the prompt with ChatGPT or another compatible image generator.
6. Bring the result back and explore variations.

**The workflow: Claude analyses → AI generates → Claude helps refine.**

## 🚀 Getting Started

1. Download `Thumbnail-Art-Director.zip` from this repository.
2. Open Claude and navigate to its Skills settings.
3. Use the available option to upload a custom Skill.
4. Upload the ZIP and enable the Skill.
5. Start by providing one or more thumbnail references.

Refer to [QUICK-START.md](QUICK-START.md) for the detailed instructions.

*Claude's interface and Skill upload options may change over time.*

## ⚠️ Important Notes

- This is an AI-assisted design workflow, not a guarantee of professional design results.
- Generated images and prompts should always be reviewed.
- The Skill analyses references supplied to it; it does not train or modify an AI model.
- Image generation depends on the capabilities and usage limits of the image-generation service you choose.
