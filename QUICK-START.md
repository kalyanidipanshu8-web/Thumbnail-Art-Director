# Thumbnail Art Director: Quick Start

## What you have

| File | What it is |
|---|---|
| `thumbnail-art-director.zip` | The Skill package. Upload or save it to use the Skill. |
| `YouTube-Thumbnail-Design-Handbook.pdf` | The full handbook: styles, theory, prompts, workflows, troubleshooting. |
| `QUICK-START.md` | This page. |

Creating the package and activating it are separate steps. The ZIP is ready. It becomes usable only after you add it to Claude (see below).

## Step 1: Activate the Skill

1. Keep `thumbnail-art-director.zip` exactly as delivered. Do not unzip and re-zip it.
2. In Claude, open the Skills area of your settings and choose to add or upload a custom Skill. Menu labels can vary by app version and plan.
3. Select the ZIP. Confirm the name reads `thumbnail-art-director`.
4. Turn it on for the conversation where you want to use it.

If you cannot find an upload option, ask Claude to propose the Skill for saving. It will show a review card you can save from.

## Step 2: Use the commands

| Command | Example |
|---|---|
| ANALYSE | `ANALYSE` + attached thumbnails |
| IDENTIFY STYLE | `IDENTIFY STYLE` + a thumbnail or a short description |
| CREATE THUMBNAIL | `CREATE THUMBNAIL` + "Topic: ..., Audience: ..., Preferred style: ..." |
| GENERATE PROMPT | `GENERATE PROMPT` + "Direction 2, [style], 16:9" |
| HYBRID STYLE | `HYBRID STYLE` + "[style A] lighting + [style B] layout, Topic: ..." |
| IMPROVE | `IMPROVE` + attached thumbnail + "Video is about ..." |
| EXPLAIN | `EXPLAIN` + "Why does ... work?" |

## Step 3: Try a starter prompt

These come from the handbook appendix. Each uses an original topic. Add the headline text in an editor afterwards.

1. **Bold Overlay Tutorial:** budget tracker in one afternoon. Headline: BUDGET IN 1 DAY.
2. **Split-Screen Comparison:** garden makeover. Labels: DAY 1 / DAY 30.
3. **Cinematic Photoreal Hero:** night power cut story. Headline: DARK (or none).
4. **Illustrative 3D Explainer:** online payments for small shops. Headline: GET PAID ONLINE.
5. **Character Macro Action:** fantasy lantern keeper. Headline: THE LAST LIGHT.

The full prompt text for each is in the Skill's `prompt-engineering-guide.md` and in the handbook.

## Step 4: Finish the image

1. Generate four variants from one prompt.
2. Pick the one with the clearest subject and empty space for text.
3. Add the headline in an editor using 2 to 4 words in a heavy weight.
4. Check it at small size (about 10 percent of full size).

## Rules to keep

- Describe people generically. Do not name real people or use their likeness in prompts.
- Do not add brand logos or trademarked characters. Use generic symbols.
- Generate without text where possible, then add text yourself.
- Colour values are visual estimates. Adjust them to your brand.
- The reference analysis rests on a small set. Style confidence is stated in the handbook. Add more references to firm up the conclusions.

## Limits

- The Skill designs and writes prompts. It does not generate or edit images unless your session has an image tool.
- It explains design choices only. It makes no claims about views, clicks, or growth.
